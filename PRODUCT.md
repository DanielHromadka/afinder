# aFinder

## Register

product

## Users

People managing local and remote files on macOS, Windows and Linux, including developers working with Claude Code and Codex in the integrated console.

## Product Purpose

Combine everyday file browsing, previews and file operations with optional agent and terminal workflows in one desktop window.

## Brand Personality

Familiar, compact, practical. Preserve the existing selectable themes and the application's Finder and Windows Explorer conventions.

## Anti-references

Avoid replacing the dense file manager with a dashboard or decorative card interface. Layout controls should use the application's existing controls.

## Design Principles

- Files remain directly accessible during agent work.
- Moving or hiding the console preserves running sessions.
- Offer useful starting layouts and allow resizing afterward.
- Persist workspace sizes and validate stored preferences.

## Accessibility & Inclusion

Localize controls in the existing four languages. Provide keyboard-operable resize separators, focus indicators and explicit labels. Do not add decorative motion.
